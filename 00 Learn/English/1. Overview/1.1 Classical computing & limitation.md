# Classical Computing and Its Limitation
## Classical Computer
Computer has their own Language! Computer use 0 and 1 -`Bit` to represent data. For example, computer store 3 as 11.
The `Bits` will pass thorough a set of `logic gates`(we will share in later sections) to perform calculation. With the advancement of the era, we need more `bits` to store our information and more complex computation to process it. Moore's Law state that the number of transistors on a chip tends to double about every two years，and computational efficiency will be improved. However, semiconductor industry meet the bottleneck in terms of physical limitation cause Moore's Law slow down. 

## How Scientific Development Related to Computer?
Today's computers no longer just calculators that speed up human arithmetic, they dictate the scale and complexity. 

During high school, almost all integrations and differentiations can be simplified using standard algebraic or calculus techniques. In reality, not all equation can be simplified or we said they are `non analytical`. Some of the analytical equations are even more complex, and we need many steps to simplify it. Therefore, we need computer to help us do these kind of job：

| | `Symbolic Computation` | `Numerical Computation` |
| --| -- | --|
|What they do?|Algorithmic manipulations of mathematical expressions| Approximate numerical solutions to complex equations|
|Output Result| $\pi$ | 3.14159....|

As the datasets become larger, a single computer definitely not enough to complete the tasks within reasonable time. `High Performance Computing(HPC)` is the practice of aggregating computing power to deliver much higher performance than standard computer. It involves connecting multiple computers(`nodes`) into a network cluster to solve massive and complex problems through **parallel processing**. In modern cases, industries are shifting toward a `Heterogeneous Architecture` where different tasks are delegated to different processors(CPUs, GPUs, ...). 

## Difficulty of Computational Problem
The difficulty of a computational problem is measured by computational complexity-how much time and memory an algorithm needed to find a solution as the input grows.

&nbsp;

- `P (Polynomial Time)`: Represent problems can be solved relatively quickly in polynomial time by a standard classical computer such as basic arithmetic or sorting
- `BPP (Bounded-error Probabilistic Polynomial Time)`: Problems solvable by a computer using randomness to find an answer quickly within manageable/small probability error. Example: problem like simulate coin flipping 10 times
- `BQP(Bounded-error Quantum Polynomial Time)`: Quantum Computer can solve efficiently with a bounded probability error.
- `NP(Nondeterministic Polynomial Time)`:These problems where if correct answers are provided, a standard computer can verify it is correct quickly, even if finding the answer from scratch take very long time. Example: Sudoku.
- `NP-Complete` Hardest problems within NP
- `PSPACE (Polynomial Space)`: Problems can be solved using reasonable(polynomial) amount of memory, even it takes unreasonable time.
- `EXPTIME (Exponential Time)`: Problems take an exponential amount of time to solve.

&nbsp;

A problem is in Class P if its "Best Possible Algorithm" has a polynomial Big O: sorting a list of numbers
- Method 1 (Bubble Sort): This is $O(n^2)$
- Method 2 (Merge Sort): This is $O(n \log n)$
Because we found a method (Merge Sort) that is $O(n \log n)$, we classify the problem of sorting as being "in P" (polynomial).
